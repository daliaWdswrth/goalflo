# goalflo
A minimalist habit and goal tracking app

## (Current) Features

- **Calendar**: Track your daily progress with emojis
- **Goals**: Set and monitor progress toward your goals
- **Journal**: Record your any reflections
- **Tasks**: Manage your to-do list
- **Resources**: Document important links and bookmarks
- **Focus**: Define your current priorities

## Tech Stack
- React
- Vite
- Tailwind CSS
- LocalStorage for data persistence

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
4. Open `http://localhost:5173`
